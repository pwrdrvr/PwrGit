# GitCafe brand asset

`favicon.svg` is the unaltered icon published at
[git.cafe/favicon.svg](https://git.cafe/favicon.svg), downloaded on 2026-09-13.
The GitCafe homepage identifies this file as its icon.

PwrGit uses it to identify GitCafe repository hosts. It does not imply
endorsement by GitCafe. The image retains its published colors and proportions
on both themes.
