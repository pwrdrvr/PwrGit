# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in public GitHub issues.

Use GitHub private vulnerability reporting if it is enabled for the
repository. If that option is unavailable, email
[security@pwrdrvr.com](mailto:security@pwrdrvr.com) with:

- a concise description of the issue and its impact;
- steps to reproduce or a minimal proof of concept;
- affected releases or commits, if known; and
- sanitized logs or screenshots that help validate the report.

Do not include secrets, access tokens, private repository contents, personal
data, or exploit material beyond what is needed to demonstrate the issue.

## Response expectations

PwrDrvr LLC will acknowledge valid reports as soon as practical, assess their
impact, and coordinate remediation and disclosure with the reporter. Please
allow time for a fix to reach supported release artifacts before publishing
details.
