2Image diff — filling the pane, and a lightbox that can compare

Two problems. Inline, the pair stays side by side down to about a 500px pane, where each picture is ~300px wide and neither is readable — and a fixed 420px cap leaves the rest of a tall pane empty. Expanded, there is nowhere to go: no zoom, no pan, no way to flip between revisions on the same pixels. The lightbox carries three items — Before, After, Diff — under one shared zoom and pan.

The rule

Stack when side-by-side would render each image under 320px wide, or when the image's own aspect makes a side under 160px tall. Above both floors keep them side by side — comparison beats size.

How it's measured

The width floor is a container query on .pane--main at 820px, so it is right at first paint with no JS. The height floor needs the decoded aspect ratio, so ImageDiff adds .diff-image--stacked once both sides report a natural size. An ultrawide banner stacks in a pane where a phone screenshot would not.

Filling the height

The 420px cap becomes viewport-relative: min(58vh, 640px) side by side, min(46vh, 560px) stacked, min(72vh, 900px) when an add or a delete leaves only one side.
