Sidebar: the row that moved says so, and offers the fix

Recommended: 2a. A preview row whose tag differs from the published remote gets a warm wash and a split value: the local hash, struck through, then an origin 0e7e3db chip. The chip is a real button that opens the same Take origin's confirm the Tags tab uses, so the fix is one click and one confirm. The data is the same stored comparison the count line already uses (SQLite, limited to the six preview names). It adds no Git process and no network call. "Kept local" rows stay quiet, and the count line stays for tags outside the preview.
