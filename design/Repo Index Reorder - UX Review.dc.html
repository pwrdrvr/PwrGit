1What PwrAgnt shipped, and what carries over

PwrAgnt #3260 lets you drag names in its project index to reorder the pinned projects, through the same rules as the Directories list’s folder drag (directory-pin-drop.ts), so the two can never disagree. PwrGit’s repository index (RepoIndex.tsx) is the same column, but the ordering model underneath differs. The port keeps PwrAgnt’s principle (the index applies the tree’s own drop) and PwrGit’s model.

PwrAgnt project indexPwrGit repository index (proposed)
What a hand order isPins sit above a hairline, in the operator’s order; the rest follow by name. Every view shows both.Only the Pinned lens is hand-ordered (lensIsArrangeable). Focused, Behind and Stale answer a question; All is A–Z. A hand order there would fight the answer.
What a drag can doMove a pin, pin an unpinned project (drop above the hairline), unpin (drop on or below it), ghost Pin slot when nothing is pinned.Move only, in the Pinned lens. Pinning stays the star. Every name in that lens is already pinned, so there is no seam to cross.
BoundariesOne flat list.Grouped by folder: a name moves inside its folder group, as tree rows do (canDrop).
GesturePointer drag (beginPointerReorderDrag): 4px lift, tilted held card, dimmed source, 3px line, Escape cancels.The tree’s own drag (useListReorder, HTML drag and drop): browser lift threshold, dimmed source, 2px accent line, Escape cancels. Same hook instance as the tree.
Keyboard⌘⇧↑/↓ on a pinned name.⌘⇧↑/↓ on a name in the Pinned lens, the tree row’s move, announced the same way; focus stays on the moved name.
After the dropThe name flashes an outline for 1.2s.No flash: the tree’s drop has none, and the selection tint already marks a moved repository you are in.

1

No new visual language

Line, dim and drag image are the tree’s. PwrAgnt’s tilted card belongs to its pointer drag; mixing both styles in one sidebar would make the index feel like a different app.

2

The hover hold is released on drop

As the tree’s drop does (held.release()), so the move shows even with the pointer parked on the column.

3

The index never scrolls itself mid-drag

Scroll-spy follow already waits while the pointer is inside; a drag marks the pointer inside too, since HTML drag fires no pointer events.

?

Left out on purpose

Drag-to-pin from other lenses (2b) and PwrAgnt’s 1.2s drop flash. Either can follow if the plain move feels too quiet.
