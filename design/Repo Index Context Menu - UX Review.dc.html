0The ask, and what this round assumes

Operator, 2026-11-17, after Pinned Repos Lead Every Lens (pwrdrvr/PwrGit#616) shipped. Their screenshot showed PwrAgnt’s project-index menu: Mark Read · Pin Directory · Show in Finder, Copy Path · Pause Forge Activity, Forge Automation…, Forge Permissions… · Clean Up Project…, Archive Threads and Remove Project.

“Seems like we didn’t get the right click context menu on the project sidebar like we have in PwrAgnt as part of #616. We should add that, to a degree, here. Make it similar / same in implementation to how PwrAgent does it.”

1

Same implementation: the index opens the row’s own menu

PwrAgnt’s openProjectIndexContextMenu looks the project up and calls the project header’s openDirectoryContextMenu; there is no second list. PwrGit does the same: a name opens the repository row’s menu, at the pointer. This is also the sidebar’s “one object, one menu” rule.

2

“To a degree”: the shared section, not PwrAgnt’s agent verbs

Gained: Pin / Unpin repository and, for a pin, Move up / Move down with their ⌘⇧↑/↓ hints, first, as in PwrAgnt. Reveal in Finder and Copy path move up under them. Mark Read, the forge-activity entries and Archive have no PwrGit object (turn 3).

3

The tree row’s menu changes too

It is the same menu, so right-click and ⋯ on a tree row gain the pin section. Nothing is removed from it.

?

Open: PwrGit’s words and density

Entries keep PwrGit’s sentence case (“Pin repository”, “Copy path”) and .pop-menu sizes. PwrAgnt’s Title Case and its denser menu (Thread Context Menu Density) are a separate, app-wide question.

3PwrAgnt’s entries, and what each becomes here

Order follows PwrAgnt: pin section, then path, then the object’s own verbs, then the leave-the-list section last.

PwrAgntPwrGitWhy
Mark ReadLeft outPwrGit has no unread state on a repository.
Pin / Unpin DirectoryPin repository / Unpin repository (new, first)Same object as the star; repo:setPin. A pin on one of its worktrees or branches does not light it, so the entry still says Pin.
Move Up / Move DownMove up / Move down (new, pins only)The existing ⌘⇧↑/↓ move through movePin, so the order is the profile’s one pin order.
Show in Finder, Copy PathReveal in Finder, Copy path (moved up)Already on the row’s menu; moved to second, as in PwrAgnt.
Pause Forge Activity, Forge Automation…, Forge Permissions…Left out; Fork…, Manage remotes…, Repository setup…, Refresh forge info stayThose govern PwrAgnt’s agents. PwrGit’s forge-side verbs are already on the menu.
Clean Up Project…, Archive Threads and Remove ProjectHide repository, Remove repository… (unchanged, last)Same place and role: leaving the list. Remove keeps its guided dialog.

Keyboard. The Menu key and ⇧F10 open the same menu from a focused index name, under the name, as they do on a tree row. Focus returns to the name on Escape.
