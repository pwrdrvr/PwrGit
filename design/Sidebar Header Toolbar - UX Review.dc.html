1bWhat is wrong with it
1

252px of controls before the first repository

Search 52, the action block 156, the lens row 44. On an 800px-tall window that is about a third of the sidebar, or eight collapsed repository rows. The list is the sidebar’s job, and it starts below the fold of its own pane.

2

Four button treatments for one tier of action

A search field, solid ghost buttons (Add folders, then Clone and Fork once a folder exists), quiet hairline buttons (Fetch, Pull) and a full-width row for Maintenance alone. Heights are 34, 32 and 30. Nothing says these are one toolbar, so the eye reads them as five unrelated things.

3

Frequency runs backwards

Add folders is done once per profile and owns the top full-width slot. Maintenance is weekly at most and owns a whole row. Fetch all and Pull all are daily and sit lowest. Jump has ⌘F and ⌘K and still takes a full row.

4

Search is not a sidebar control

The palette it opens searches repositories, worktrees, branches, pull requests, commits and files, and it is not a filter on this list. Its natural home is window chrome, which still shows when Contributions replaces the panes.

✓

The title strip has room

At the 1560px window in the screenshot, roughly 800px of the strip between the crumbs and Contributions is empty drag region. Even at the 940px minimum window, 200px or more is free once the path chip has collapsed to its folder.

All three keep every action reachable in at most two clicks, keep the lens row as it is, and use only house parts: .wt-btn’s shape for buttons, ContextMenu for menus, and hoverTooltip for names and shortcuts. 32b in detail — narrow widths, menus, day one

Nothing here steps at a fixed width. Each row steps down on measured fit (useFitLadder / useStepLadder with a ResizeObserver), in the order stated, so a longer label, a larger text size or a translation moves the step rather than overflowing. The pixel widths named below are where the steps land with today’s labels in Geist Sans. They are not constants to build.

Order: key cap → label → then the crumbs’ existing shrink (the path chip to its folder, then the repository name’s ellipsis). The crumbs name where you are, and the field is decoration once you know ⌘F. So the field gives way first: a step is taken while the crumb row is truncated, measured as natural width against box width, not by window width. At the 940px minimum window with a long branch name it lands on the 30px icon. That square is still a field-shaped button, with the same border and the same hover, and its name stays “Jump to repo…” for assistive tech and E2E. On Windows it sits left of the 150px caption-button reserve, and on Linux left of WindowControls. Like every strip control it opts out of the drag region.

Today Add folders leads the stack because on a new profile it is the only control that works. With the stack gone, the empty list takes over that job, as PwrAgent’s SidebarStartActions did for its own empty list. A profile with no folders gets the button and the sentence in the list.
