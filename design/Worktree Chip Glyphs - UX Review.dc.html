1 Findings — the worktree chip draws its marks with text characters

The chip that says which worktree holds a branch (sidebar branch rows, sidebar PR rows, and since #398 the refs browser) leads with ⌂ for the primary checkout and ⑂ for a linked worktree. Both are Unicode characters, not glyphs. The same ⑂ is also the leading icon on every branch row. Specimens use contrived names. Source: WorktreeHolderChip.tsx, RepoChangeRequestSection.tsx, RepoRefsSections.tsx.

1cWhat is wrong
1

Neither character is in the bundled faces

⑂ is U+2442 OCR FORK and ⌂ is U+2302. Geist Mono’s subsets do not cover either range, and measured in Chromium both characters have the identical advance in Geist Sans and Geist Mono (23.52 and 24.09 px at 40 px, where a differs) — one OS fallback font draws them in both. So weight, size and baseline come from some other font and change per platform, the same reason styles/AGENTS.md bans ↻ for refresh.

2

The sidebar’s PR chip always says “primary, here”

It draws ⌂ and the filled is-here treatment for every PR whose head is checked out, even in a linked worktree that is not the working target. The branch chip beside it gets both right. The refs browser follows the branch chip, so the two surfaces disagree.

3

The SVG family is split too

CheckoutGlyph is the house the lineage graph’s ref chips and the sidebar’s remote rows draw for “checked out”. But “branch” has two drawings: the graph’s ref chips use Lucide’s git-branch (GraphRow’s BranchGlyph), the ⌘K palette’s branch rows use a custom one (BranchIcon) — and the palette draws its worktree rows with the graph’s branch. One drawing means branch in one place and worktree in another.

2 Options — one row of the house family for primary, linked, and the branch beside them

Every option replaces the leading branch character with the graph’s branch (Lucide git-branch, as its ref chips draw it) and the primary mark with CheckoutGlyph; they differ in the linked worktree. Each is drawn with the branch icon in the same row, because that is the neighbour the chip has to read apart from (“A 15 px glyph separates by silhouette”). Top: sidebar rows at 10 px. Bottom: the refs browser’s action-slot chip at 12 px.
