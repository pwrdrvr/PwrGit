Aspirational — explored, not built

Agent-drafted rebase plans

The 2026-08 wireframe drew an Agent rail tab — a “Rebase assistant · Codex · gpt-5.5 · ACP” that drafted a rebase plan for you to approve, reached by an Ask agent → button. No model is wired into PwrGit. What shipped instead is the deterministic Rebase tool in the frame above: rebase:draft builds the plan from the selection, Check in isolated copy replays it in a disposable clone and returns an approval token, and only a clean check enables Apply.

A quieter multi-lane lineage

Lane reuse, dashed remote lineage and the Active/All scope toggle all ship. Still open: automatically dropping branches that have been merged or squash-landed so the graph stays quiet without being told, rather than leaning on the scope toggle and Settings › Experimental › lineageAllBranches.
