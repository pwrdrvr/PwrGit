1aFour findings against BulkSyncDialog as built
1

A 16-second run blocks the whole window

The backdrop ignores clicks while running. The only way back to the app is Cancel, which throws the run away.

2

Escape cancels instead of hiding

useModal’s onClose unmounts the dialog, and the unmount cancels the operation. A reflexive Escape loses the fetch.

3

Fetch has one scope

48 repositories every time, even when the reader works in five. The Focused lens already knows which five.

4

Nothing fetches on its own

Ahead/behind counts go stale until someone remembers to press Fetch all.

2The run outlives its dialog — minimise to a toast, expand back

The run moves out of the dialog into a component that stays mounted while either view is up. The dialog gains a Minimise button in its head; a click on the backdrop or Escape does the same while running. The card shrinks onto the toast’s rectangle, so the eye follows it to the corner. Contrived data.

2fThe remembered view
1

First run ever: the dialog, then it shrinks itself

With no remembered view, the dialog opens and minimises itself after 4 s unless the pointer has moved over it or a key was pressed in it. Focus is no signal: the dialog takes focus as it opens. That teaches where the toast lives. Remembered: toast.

2

Minimise (button, backdrop, Escape) remembers toast

The next Fetch all opens straight to the toast.

3

Expanding the toast remembers dialog

The next run opens as the dialog and stays put — no auto-shrink once the reader has chosen. One preference covers Fetch all and Pull all.

4

Close is still Close

After the run, a backdrop click or Escape closes, as today. Cancel is the toast’s × while running, Dismiss once finished.

3Fetch ▾ — a sticky scope and a schedule

Fetch all becomes a split button. The face runs the remembered scope and wears its name; the chevron opens a menu of scopes and intervals. Picking a scope runs it now and makes it the face. Recent is the Focused lens’s list (current, pinned, viewed, changed, or committed to in 30 days) — no new definition of “recent”. The accessible names stay “Fetch all repos” / “Fetch recent repos”, so voice control and E2E keep finding them.

4Assumptions to check
?

Recent = the Focused list

Reuses the lens the reader already trusts. If “recent” should mean something narrower (only viewed in 7 days), that is one function.

?

Timed runs are silent, even on failure

A repository that always fails (no access) would otherwise raise a toast every interval. The tooltip carries the last timed result instead.

?

Settings are per machine, not per profile

Scope, interval and view are localStorage. Per profile is a key change if wanted.

?

The toast sits bottom-left

Near the sidebar that started it, and clear of the bottom-right error stack it would otherwise push around.

5One sync button — Fetch and Pull share a face and a menu

Operator’s ask, 2026-10-28: “Pull all and Fetch are very similar… both should probably have the same chevron and options? Maybe they should be one button?” Chosen: one button. Try pull already fetches every repository before it fast-forwards, so two buttons offered the same first half twice — and as two flex items, Fetch ▾ and Pull all could not even agree on a width (the chevron’s wrapper has no padding, so a zero basis gave Pull all its 20 px of padding and border as a head start). This turn supersedes turn 3’s row; the menu’s automatic interval and the quiet timed run are unchanged.

5bRules
1

Four actions, one radio group

Fetch or Pull, all or recent. Picking one runs it and makes it the face: Fetch all, Fetch recent, Pull all, Pull recent.

2

Names keep the old buttons’ words

“Fetch all repos”, “Fetch recent repos”, “Try pull all”, “Try pull recent”, so voice control and E2E still find them. The chevron is “Sync options”.

3

Timed runs only fetch

Even with Pull on the face. Pulling on a timer would move checkouts under the reader.

4

Busy reads per glyph

Fetch’s circular arrow turns; Pull’s down arrow swaps to the ring, as on the worktree toolbar.

5

The row gets a slot back

One grower between Add and the wrench, so “Fetch recent” and “Pull recent” keep their words at widths where two buttons dropped to glyphs.
