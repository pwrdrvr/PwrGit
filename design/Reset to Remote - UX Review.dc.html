Reset mode5
SoftMove the branch and HEAD to the selected commit without changing the index or working tree. File contents and existing staged/unstaged work stay in place; Git reports their differences against the new HEAD.
Hard · destructiveMove the branch and HEAD, reset the index, and overwrite tracked files. This discards tracked staged and unstaged changes. Untracked and ignored files are normally left alone, but Git may delete an untracked file or directory that obstructs a tracked path in the target commit. This does not run git clean.

Both modes move the local branch pointer to origin/main. Any local commits that are not reachable from that target leave the branch. Git's reflog may retain them temporarily; do not rely on that as a backup.

6
1

"Fetched" is a caveat with no controls

The reset targets the last fetch, not the live remote. Nothing says when that was, and there is no way to refresh from here. A stale origin resets you to yesterday's tip, silently.

2

Defaults to origin/main, not your upstream

The picker seeds itself with the first row of a list sorted newest-commit-first across every remote. The branch's own upstream — origin/fix/1.1-windows-media-copy, the answer almost every time — is somewhere below the fold. One confirm resets a feature branch onto trunk.

3

Eight-row listbox renders one row

size={8} is overridden in CSS: .refs-field select { height: 34px } lands after .branch-picker__list select { height: auto } at equal specificity, so the later rule wins. 39 branches paged through a one-row porthole. The push dialog shares the control and the bug.

4

The only clue that 39 exist

10.5px muted text, bottom-right, underneath a control that shows one row. It reads as a footnote, not as "there is a list here".

5

Both modes look equally safe

Identical neutral cards. "Hard · destructive" carries the word but none of the colour, and its 62-word paragraph of Git semantics is longer than anything that tells you what happens to your work.

6

Amber CTA regardless of mode

The step-1 button stays the accent colour even when Hard is selected; danger styling appears only on the final button, one screen later.

7

Never says what you lose

The worktree already knows it is 9 ahead and has uncommitted files. Neither number appears on either screen — only prose about reachability and two 40-character SHAs on the confirm step.

8

One way in

The graph header's kebab, and nowhere else. The sidebar worktree row renders the same menu component without the item, and the diverged-pull dialog — where you most want this — does not offer it.

Turn 2 reworks the target step, 3 the confirm step, 4 the entry points.
